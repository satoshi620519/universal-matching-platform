# Marketplace Evaluation Matrix

Use this matrix before selecting a sales channel. Scores must be based on current marketplace rules at the time of publication.

| Criterion | Weight | Candidate evidence |
| --- | ---: | --- |
| Source-code product fit | High | Product/category policy |
| App template fit | High | Existing template categories |
| International reach | High | Buyer geography and payment support |
| License compatibility | High | Seller terms |
| Seller eligibility | High | Verification requirements |
| Payout availability | High | Supported payout methods |
| Refund/support burden | Medium | Marketplace policy |
| Asset requirements | Medium | Listing rules |
| Update obligations | Medium | Seller obligations |
| Fees | Medium | Current fee schedule |

## Candidate decision record

For each candidate record:

- marketplace name
- official policy evidence URL
- evaluation date
- accepted product category
- restrictions found
- required listing assets
- seller/payout constraints
- provisional decision: shortlist / reject / publish

Do not record a marketplace as approved without current official-policy verification.
