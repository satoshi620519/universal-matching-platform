# License Decision Required Before Marketplace Release

The repository is currently marked private and does not contain a buyer-facing license file. A license must be chosen deliberately before distributing source code.

## Release blocker
Do not package or sell a source-code release until the rights granted to the buyer are explicitly defined.

## Decision to record
The project owner must select one commercial distribution model and add the corresponding reviewed license text:
- single-product commercial license
- marketplace-standard commercial license
- dual license
- another legally reviewed proprietary license

## Important
Do not copy an open-source license merely to satisfy a checklist. License choice affects redistribution, modification, resale, support expectations and marketplace compatibility.

After the owner chooses the distribution model, replace this decision record with the approved buyer-facing LICENSE file and update the release checklist.
