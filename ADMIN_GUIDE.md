# Administrator Guide

## Purpose

Use this guide to operate the Universal Matching Platform after installation. Administration should use the normal authorization and capability boundaries; Quick Launch configuration is not a substitute for administrative access control.

## First launch

1. Complete the Admin Quick Launch workflow.
2. Save the configuration as a draft.
3. Review branding, regions, categories, profile fields, features, legal/support links, terminology, matching rules, and onboarding.
4. Publish the reviewed configuration.
5. Use Published & history to confirm the active immutable version.

## Quick Launch steps

The purchaser-facing workflow contains:

1. Branding
2. Regions
3. Categories
4. Profile Schema
5. Matching Categories
6. Features
7. Legal & Support
8. Terminology
9. Matching Rules
10. Onboarding
11. Review & Publish

Changes remain drafts until publication. A publication is immutable; later changes require a new version.

## Operational administration

The Admin application includes normal workspaces for moderation, analytics, failed outbound email, administrative roles, system health, and administrative accounts. Access remains subject to server-side authorization.

Do not use client-side visibility settings to grant privileges. Keep production secrets and provider credentials outside purchaser configuration.

## Before public launch

- verify legal and support destinations
- restrict administrative access
- review enabled features
- verify supported countries/locales
- confirm the published configuration
- complete deployment and security checks
