# Universal Matching Platform — Project Master

## Vision
Create a highly polished, commercially sellable universal matching application platform that feels comparable to professionally engineered software, not merely an AI-generated template.

## Core concept
One system should support many matching businesses and communities, including:
- Dating
- Business matching
- Mentorship
- Communities
- Other niche matching services

## Product goals
- Web + iOS + Android
- Safe and easy to use
- Works out of the box after branding changes
- Also customizable at source-code level
- International-ready
- Country and region-aware matching
- High-quality, commercially viable finished product
- Designed for one-time/license sales rather than requiring the creator to operate a long-term SaaS

## Two buyer modes
### Quick Launch
Buyer changes logo, colors, images and basic configuration, then can launch quickly.

### Advanced Customization
Buyer/developer can modify source code and add or change functionality.

## Development principle
Do not rely on chat memory as the source of truth. GitHub documentation and source code are the project record.
