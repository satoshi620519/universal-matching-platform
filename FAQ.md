# Frequently Asked Questions

## Can I launch without editing source code?

Yes. Use Admin Quick Launch for branding, regions, categories, profile schema, feature visibility, terminology, matching rules, onboarding, and publication.

## Can developers customize the source?

Yes, within supported extension boundaries. See DEVELOPER_GUIDE.md and DEVELOPER_EXTENSIBILITY.md.

## Does this repository include Web and mobile products?

The repository contains Web, Admin/API, and mobile source-product components. Follow MOBILE_ACCEPTANCE_CHECKLIST.md for mobile acceptance.

## How are configuration changes released?

Quick Launch changes are saved as drafts and explicitly published as immutable versions. Publication history preserves previous versions.

## How should I deploy a demo?

Use an isolated environment and follow DEMO_DEPLOYMENT_SPEC.md.

## Can I reset a production database with demo reset?

No. Demo reset is explicitly guarded and scoped to the fictional demo baseline. Production operations require separate deployment procedures.

## What license applies?

A final commercial distribution license must be selected by the owner before marketplace release. See LICENSE_DECISION_REQUIRED.md.

## Where do I report a vulnerability?

Use the private security contact configured by the deployment owner and follow SECURITY.md.
